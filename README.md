## Pre-requisites
1. Install Spark version 3.4.1.
    - 1.1. Determine Spark Session
        - Check the exact version of Spark you’re using. This information is crucial for selecting the compatible JAR file.
    - 1.2. Visit the Maven repository:
        - Access the following link: https://mvnrepository.com/artifact/net.snowflake/spark-snowflake
        - This repository hosts various versions of the Spark Snowflake connector JAR files.
    - 1.3. Find the suitable JAR version:
    - 1.4. Download the JAR file:
        - For Spark Snowflake Connector: https://repo1.maven.org/maven2/net/snowflake/spark-snowflake_2.12/
        - For Snowflake JDBC Driver: https://repo1.maven.org/maven2/net/snowflake/snowflake-jdbc/

2. Install Airflow on Docker.
